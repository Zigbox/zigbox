# M8 slice 12: credentials, handoff note

Decisions:

- Credentials come only from `--password-file` (regular file, mode 0600 or tighter) or
  `--password-stdin`; there is no `--password`, environment variable or config file, so a secret
  is never on a command line. The pair is bounded by `push_credential_bytes_max` (4096).
- The token's scope is what the push needs, built by us; the challenge's scope is ignored.
- E0558 is wider than the brief's wording (stdin, missing, link, unreadable, `:` in the user).
- The password is read, used and wiped in the forked push child (`Credentials.wipe`).

Traps found:

- `Rig` in the tests is `page_allocator.create`d, so struct defaults are not applied.
- The sim's `open_count` underflowed when a forked command created the stdin pipe
  (`World.input_is_held_by_first`).
- Diag context keys are at most 6 bytes; codes.zig explanation lines at most 76 characters.
- There is no golden-update mechanism; goldens were generated by dumping from the test.
- The registry fixture's `leaked` counts credentialed requests to a host that is not the
  registry; tests and the fuzzer assert it is 0.

Review fixes (PR #76):

- Basic and Bearer are exclusive: a token replaces the Basic credential and the other way
  round, each wiped on the switch, so a registry that changes its challenge never gets both.
- After a network call that carried a credential, the request head and the read and write
  buffers of the network memory are zeroed (`wipe_buffers` in host_real_net.zig).
- The realm rule compares host names, not ports, on purpose: the realm is the registry's own
  host, and the registry's token service and API commonly sit on different ports of it.
- Not done: refusing a password file owned by another user (the review's NIT); it needs a
  `geteuid` on the host interface and is left to the supervisor.

Trap found by the live run: the simulated host accepts a read of standard input with no open file;
`HostReal.read` did not. Any new use of a host call the simulator and the real host implement
separately needs a real run, not only the simulation.
