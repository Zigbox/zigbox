# 0.5.3 scope: M6d and M2b

*Decided 2026-11-16, by the owner.*

0.5.3 is M6d (private pull from Artifact Registry and gcr.io) and M2b (workload knobs: rlimits,
/dev/shm size, NUMA syscalls, namespaced sysctls, host preflight, cgroup namespace). M2b moves
from 0.6.x to 0.5.3 (owner, 2026-11-16). 0.6.0 is still S2. Cap-add stays parked; io_uring,
cpuset/io/hugetlb and nested containers stay non-goals.

This changes only the target release named in
[2026-11-16-m2b-workload-knobs.md](2026-11-16-m2b-workload-knobs.md); the rest of that decision
stands. Detail: [the M2b brief](../briefs/M2b-workload-knobs.md), the M6d brief and
[the spec](../SPEC.md).
