# `Fs.read_at`: positioned reads for chunk serving
*Decided 2026-11-03, by the Z1/Z5 slice.*

`store.read_chunk` (Z1) must read chunk `i` of a large file. `Fs` had no seek, so reaching chunk `i` by sequential reads makes serving every chunk quadratic in the file size. The vtable gains `read_at(fd, offset, buffer)` and `Fs.read_full_at` (retries short reads like `read_full`). The real host uses `pread`; the simulator is offset-based and keeps its short-read and read-error fault injection; the host sink returns 0. Existing callers do not use it and are unchanged.

See `src/store/fs.zig`, `src/store/chunk_read.zig`.
