# 0.5.1 ships M9 and M10 as experimental

*Decided 2026-11-13, by the owner.*

Zigbox 0.5.1 ships the M9 (Dockerfile import and the builder slices merged by then) and M10
work that is on `main` at the release commit, marked **experimental**. The release does not wait
for either milestone's last slice or its live demo.

What "experimental" means for 0.5.1:

- The release notes, the README and the project site call both features experimental and say
  which slices are in and which are not.
- Their commands, flags, file formats and error codes may change in a later release without a
  deprecation period.
- Every other release rule still holds: the release commit is sim-clean, `zig build check`
  passes on it, the demos of every milestone already demonstrated stay green, and two
  independent reviewers review the diff since 0.5.0.
- A milestone is still marked "demonstrated" only once its `demo-mN` job is green in CI.

Reason: the owner wants the shortest time to release; 0.5.1 is an honest public beta (Debian and
Fedora only), and labelling unfinished milestones experimental is honest about their state
without holding back the rest of the release.
