# M8 slice 11: review fixes

Date: 2026-11-09. Context: PR #75 review 5821241053.

- **Missing `Docker-Content-Digest` on the manifest PUT:** confirm with a HEAD of the manifest
  (`Accept` is the OCI manifest type) and compare its digest with ours; refuse (E0556) when the
  HEAD fails or differs. Chosen over refusing at once because the spec makes the header optional
  for a PUT, and over trusting the 201 because a registry that stored other bytes would go
  unseen.
- **Push order:** config first, then layer (`Report.blobs()` follows it). The golden E0555
  digests changed with it.
- **Other-origin upload `Location`:** followed through `client.follow`. Each request takes its
  bearer from `bearer_for(origin)`, which is empty unless the origin is the destination's, so
  slice 12 cannot send credentials to a storage host by accident.
- **Over-bound chunk count:** refused with the existing E0555 (a blob refusal, new context
  `chunk`) before any request. No new code.
- **Tag-record warning (`run.zig`):** not added; it needs a new code, which needs the
  supervisor's word. Left as the code was, with the reason in `docs/demos/m8.md`.
