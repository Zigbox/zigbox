# Release 0.3.1: Z9 for Zigcube C2, with the xattr and exec-history fixes (owner, 2026-11-04)

Zigbox 0.3.1 is cut once Z9 (a verified chunk read outside the store namespace, branch
`claude/z9-chunk-owner`) merges. It contains Z9, the xattr import fix (#45) and the exec-history
fix (#47). This supersedes the "no 0.3.1" line of
docs/decisions/2026-11-04-package-signing-hosting.md: Z9 blocks Zigcube's demo-c2 (steps 1 and 3),
because a one-chunk object owned by a container id other than 0, such as `etc/shadow`, cannot be
served to a peer, and C2 pins only released Zigbox.

least 100 times the per-commit default finds nothing, two independent Opus reviews of the diff
since v0.3.0 have every MUST fixed or accepted in writing, and a retro follows in
`docs/retros/0.3.1.md`. Zigcube moves its pin to v0.3.1.
