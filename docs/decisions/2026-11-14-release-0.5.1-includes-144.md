*Decided 2026-11-14, by the supervisor, for the 0.5.1 release.*

[#144](https://github.com/Zigbox/zigbox/pull/144) ("Export the package writer for Zigcube (ZB-1);
pin exec against supervisor-started containers (ZB-2)",
[decision](2026-11-13-zigcube-zb1-zb2.md)) merged to `main` as 0eac6d6 after

pass. That counts as its release review coverage; the two release reviewers' diff is the
branch's diff before #144.

  files and contains none of the changed files; `fuzz_openpgp.zig` imports
  `package/openpgp.zig`, which #144 did not change.

  entry (`.zig-cache/o/165d915d…`) without recompiling: Zig's manifest for that build lists every
