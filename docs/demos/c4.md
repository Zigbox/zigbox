# C4 demo notes (Zigbox 0.5.2)

`zig build demo-c4` runs seven steps in the test VM, as the unprivileged `demo` user, against
the Alpine rootfs. The brief is [docs/briefs/zb-c4.md](../briefs/zb-c4.md), the decisions are in
[2026-11-14-zigcube-c4-requests.md](../decisions/2026-11-14-zigcube-c4-requests.md).

| Step | Proves |
|------|--------|
| 1 `start.py` | a `--net none` container holds only `lo` |
| 2 `listen.py` | ZB-5: listeners on 127.77.x.y are made live in the container's net namespace, answer inside, are not reachable from the host, and are gone when closed |
| 3 `connect.py` | ZB-5, ZB-8 (the brief's step 7): a held socket survives an adopting agent's SIGKILL and the supervisor's own re-exec (same pid, new image, only the socket kept); the new image adopts the container by name and the socket connects to a server inside |
| 4 `net.py` | ZB-7 (the brief's step 6): `zbx exec` joins the container's net namespace |
| 5 `hostile.py` | the workload cannot see, signal or `ptrace` the supervisor (ESRCH), `kill -1` leaves both alive, `/etc/hosts` is not writable, and its `/proc` shows no helper while the supervisor makes and closes 3000 sockets |
| 6 `refuse.py` | E0610 (`--net host`), E0402, E0220: one line, coded, no errno |
| 7 `hosts.py` | ZB-6: `--hosts-file` is read-only at `/etc/hosts`; an in-place rewrite is seen, a rename over the path is not; refused with E0612: `--net host`, a missing path, a directory, a file this user cannot read |

## Scope cuts

- **`--hosts-file` is not recorded.** The run record stays at version 10, so nothing that
  reads it (`zbx ps`, a bundle, an adopting agent) knows the path, and a container run again
  gets the file only when it is given `--hosts-file` again (decision file, ZB-6). Zigbox has
  no command that starts a stopped container. Not demonstrated.
- **`--net user` gets no sockets.** `container_socket` refuses it with E0610, like
  `--net host`; only `--net none` is offered. Shown in the simulator, not in the VM.
- **No IPv6, UDP or Unix sockets** (Non-goals of the brief).
- **No second kernel.** The demo runs one guest kernel (Ubuntu 24.04); other kernels are
  not exercised.
